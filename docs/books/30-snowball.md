# 《滚雪球：巴菲特和他的财富人生（下）》提要

- 分层：拓展阅读（非交易规则）
- 作者：艾丽斯·施罗德 (Alice Schroeder)（2008 年）
- 主题：巴菲特传记与复利人生
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 复利是财富的核心机制，时间与耐心是最大的杠杆。
2. 巴菲特的成功源于长期主义的习惯与持续学习。
3. 声誉与诚信是长期最重要的资产。
4. 投资与人生都遵循「滚雪球」：找到湿的雪和长长的坡。

## 可执行方法

- 尽早开始投资，让时间发挥作用。
- 建立并坚持自己的原则，不被市场与舆论左右。
- 持续阅读与思考，扩展能力圈。
- 把投资视为企业所有权，长期持有优质资产。

## 常见陷阱

- 急于求成，追求短期暴利。
- 因情绪与外界压力破坏自己的原则。
- 忽视声誉与诚信的长期价值。
