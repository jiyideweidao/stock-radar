# 《怎样选择成长股》提要

- 分层：进阶类
- 作者：菲利普·费雪 (Philip Fisher)（1958 年）
- 主题：成长股调研
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 用「闲聊法」调研：向客户、供应商、竞争对手、员工打听公司的真实情况。
2. 增长的质量比速度更重要：能持续增长且有利润率的公司才有价值。
3. 管理层的能力与诚信，是长期投资的隐形资产。
4. 好公司值得在合理价格长期持有，而非频繁买卖。

## 可执行方法

- 用十五个要点筛选：产品市场潜力、研发效率、销售组织、利润率及改善空间、管理层诚信等。
- 用「闲聊法」做定性调研，补充财报之外的证据。
- 集中投资于少数经过深入研究的成长股，长期持有。
- 买入后定期复查基本面是否变坏，而非看股价。

## 常见陷阱

- 为成长付出过高价格。
- 只看增长率，不看增长的质量与可持续性。
- 因为短期波动卖出真正的好公司。
