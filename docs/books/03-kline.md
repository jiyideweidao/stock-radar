# 《K线图》类技术分析读物提要

- 说明：中文市场存在多个同名或近名的 K 线图入门读物，作者与版本较多，此处为方法论归纳而非某一版本的原文摘录。
- 主题：K 线语言、形态识别、位置与量能的配合。

## 核心观点

1. 单根 K 线看实体与影线的比例；多根 K 线看彼此的相对位置。
2. 形态的名称不重要，出现的位置才重要：高位、低位、趋势中，还是平台边缘。
3. 成交量是确认器，不是预测器。没有量能配合的形态只能算「待确认」。
4. 同样一根长上影，在上涨末端是抛压，在底部试盘阶段可能是洗盘。

## 可执行方法

- **低位放量长下影（锤子线）**：说明有承接，等待次日收阳确认再考虑介入。
- **高位放量长上影或十字星**：抛压出现，考虑减仓或至少不再加仓。
- **阳包阴 / 阴包阳（吞没形态）**：在趋势末端参考价值更高，在中继位置意义有限。
- **缩量小阳连续上行后突然放量长阴**：警惕主力出货。
- **缺口**：向上跳空缺口未回补视为强势；向下缺口未回补视为压制。

## 常见陷阱

- 只看单根 K 线就下结论，忽略位置与量能。
- 把形态当成必然规律，忽视大盘与板块环境。
- 在日线形态上做强判断，却没有看周线方向。
