# 《聪明的投资者（第4版）》提要

- 分层：进阶类
- 作者：本杰明·格雷厄姆 (Benjamin Graham)（1949 年）
- 主题：价值投资奠基
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资与投机的区别：投资基于深入分析、本金安全与满意回报，否则就是投机。
2. 市场先生寓言：把市场当成情绪化的报价人，利用他而不是被他左右。
3. 安全边际：买入价显著低于内在价值，是投资的中心思想。
4. 分散化：用一组低估证券建立防御，而不是集中押注。

## 可执行方法

- 区分防御型与进取型投资者，选与自己时间精力匹配的策略。
- 用「估值—质量」双重标准筛选，拒绝付过高价格。
- 用股债比例（如50/50）动态再平衡，控制整体风险。
- 逆向思考：在悲观时买入，在狂热时谨慎。

## 常见陷阱

- 把股价上涨当成投资成功的标准。
- 在市场狂热时追高，忘记安全边际。
- 把投机包装成投资，加杠杆放大风险。
