# 《小狗钱钱》提要

- 分层：拓展阅读（非交易规则）
- 作者：博多·舍费尔 (Bodo Schafer)（2000 年）
- 说明：面向青少年的理财启蒙书，方法同样适用于成人建立记账、储蓄与长期投资习惯。
- 主题：金钱观与理财启蒙
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 金钱是中性的工具；贫穷或富有主要来自习惯与观念，而不是运气。
2. 储蓄优先：收入先分配，先存后花，而不是花剩下的再存。
3. 复利靠时间：越早开始、坚持越久，结果差距越大。
4. 收入来自为他人解决问题；能力越稀缺，回报越高。

## 可执行方法

- 收入三分法：约50%日常开支、40%养「金鹅」（长期投资）、10%梦想账户。
- 写下10个想变富的理由，挑3个做成梦想相册，定期回看以保持动力。
- 遇到「买不起」先问「怎样才能买得起」，把否定句改成方案。
- 第一次投资选简单、分散、长期的产品，长期持有、不频繁操作。

## 常见陷阱

- 把消费当成奖励，收入涨了开支同步膨胀。
- 用负债换取即时满足，把「想要」当成「需要」。
- 把储蓄当作「花剩下的」，永远存不下钱。
