# 《超越人性：穿越牛熊的投资心性》提要

- 分层：进阶类
- 作者：李大霄（2016 年）
- 说明：以牛熊周期中的投资者心态为主线，强调纪律与逆向思维，属实战观点整理。
- 主题：投资心性与情绪管理
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资最大的敌人是自己的人性：贪婪与恐惧制造了大部分亏损。
2. 牛熊转换中，心态与纪律比技巧更重要。
3. 用逆向思维看待市场情绪的两端。
4. 长期视角能熨平短期波动带来的焦虑。

## 可执行方法

- 制定纪律并严格执行：仓位上限、止损规则、买入条件。
- 极度悲观时保持理性，极度乐观时保持警惕。
- 用「闲钱投资」与「不杠杆」降低心理压力。
- 把注意力放在资产质量与估值上，而不是短期涨跌。

## 常见陷阱

- 追涨杀跌，情绪化交易。
- 牛市顶点满仓，熊市底部恐慌离场。
- 把运气当能力，过度自信。
