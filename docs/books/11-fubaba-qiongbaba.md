# 《富爸爸穷爸爸》提要

- 分层：拓展阅读（非交易规则）
- 作者：罗伯特·清崎 (Robert Kiyosaki)（1997 年）
- 主题：资产与负债的思维
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 资产是把钱放进你口袋的东西；负债是把钱从你口袋拿走的东西。
2. 富人买入资产，穷人和中产买入自以为是资产的负债。
3. 为学习而工作，而不是只为工资而工作；财务智商比涨薪更重要。
4. 关注自己的事业：让钱为你工作是最终目标。

## 可执行方法

- 先扩大资产项，再用资产产生的现金流去消费。
- 记账并画出自己的现金流图，看清钱从哪来、到哪去。
- 把工资的一部分持续转化为能产生现金流的资产。
- 主动补财务知识：会计、投资、市场、法律。

## 常见陷阱

- 把自住房、汽车等持续支出的项目当成资产。
- 收入提高后立刻升级消费，现金流永远紧绷。
- 只靠一份工资，没有第二条现金流。
