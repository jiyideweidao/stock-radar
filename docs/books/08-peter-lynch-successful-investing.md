# 《彼得·林奇的成功投资》提要

- 分层：基础类
- 作者：彼得·林奇 (Peter Lynch) / 约翰·罗瑟查尔德（1989 年）
- 主题：常识选股与生活调研
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 业余投资者可以利用日常生活发现好公司，优势是不受考核约束、能长期持有。
2. 只投资你了解、并能用两分钟讲清楚的公司；不懂不碰。
3. 股价长期跟随盈利，短期跟随情绪。
4. 公司分六类：缓慢增长、稳健增长、快速增长、周期、困境反转、资产富余，各类买卖逻辑不同。

## 可执行方法

- 买入前写「两分钟独白」：用两分钟说清为什么买。
- 从身边（工作、消费、货架）找线索，再回到财报验证。
- 按公司类型区别对待：周期股在景气顶点卖出，成长股看增长能否持续。
- 定期检查「故事」有没有变坏，而不是盯着股价涨跌。

## 常见陷阱

- 因为股价跌了就觉得公司变差，因为涨了就觉得变好。
- 买「名字好听」的公司，或追热门题材。
- 为还没兑现的概念（「下一个某某」）提前付费。
