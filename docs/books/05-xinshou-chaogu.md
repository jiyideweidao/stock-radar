# 《新手炒股》类入门读物提要

- 说明：中文市场存在多个同类入门读物，此处为方法论归纳，非特定版本原文摘录。
- 主题：入门常识、资金管理、避免致命错误。

## 核心观点

1. 先学会不亏，再谈盈利。本金是唯一的筹码，亏掉 50% 需要涨 100% 才能回本。
2. 只用闲钱投资，不加杠杆，不借钱炒股，不用短期要用的钱入市。
3. 认知圈决定收益率：不懂的行业不要重仓，赚不到看不懂的钱是常态。

## 可执行方法

- 下单前写下「买入理由」与「卖出条件」，两者齐备才动手。
- 分散到 3 至 5 个不同行业，单只个股不超过总仓位的 30%。
- 新手更适合定期定额，用时间分散代替择时焦虑。
- 每笔交易先确定止损价，再倒推可买数量。

## 常见陷阱

- 追涨杀跌：在情绪最高点买入，在恐慌最低点卖出。
- 听消息买股：把他人结论当作自己的研究。
- 频繁交易：手续费与滑点会持续侵蚀本金。
- 盈利就跑、亏损死扛：处置效应是散户最常见的亏损模式。
