# 《交易心理分析》提要

- 作者：马克·道格拉斯（Mark Douglas），英文原书《Trading in the Zone》，2000 年出版。
- 主题：概率思维、执行纪律、情绪管理。

## 交易的五个基本事实

1. 任何事都可能发生。
2. 不需要预知未来就能赚钱。
3. 盈亏在单笔之间随机分布，优势只在样本量上体现。
4. 优势（edge）只是概率上的倾斜，不是确定性。
5. 每个时刻都是独一无二的，历史不会精确重复。

## 核心观点

- 市场是中性的，涨跌不针对任何人；痛苦来自你自己的预期与「应该」。
- 优势必须配合「无条件执行」才有意义。犹豫与临时改规则会摧毁正期望系统。
- 目标不是判断对，而是按规则重复执行高概率动作。

## 可执行方法

- 把每笔交易视为独立事件，用 20 笔、50 笔的样本评价体系，而不是用单笔盈亏评价自己。
- 事先写下「市场证明我错了」的具体价格，然后机械止损，不在盘中重新解释。
- 记录交易日志：入场依据、当时情绪、是否违反规则。复盘时先看违规次数，再看盈亏。

## 常见陷阱

- 报复性交易：刚亏损就立刻加大仓位想赚回来。
- 连亏后放大仓位、连盈后过度自信——两者都是同一类情绪失控。
- 用「这次不一样」为破坏规则找理由。
