# 《安全边际》提要

- 分层：高阶类
- 作者：塞思·卡拉曼 (Seth Klarman)（1991 年）
- 主题：价值投资与风险控制
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 价值投资的核心是「安全边际」：以显著低于内在价值的价格买入。
2. 风险不是波动，而是永久性资本损失。
3. 绝对收益思维，而非相对收益（不跟指数比）。
4. 自下而上选股，重视下行保护。

## 可执行方法

- 自下而上筛选被低估的证券，逐个做基本面分析。
- 用「绝对收益」目标管理组合，而不是相对排名。
- 保持现金与灵活性，等待真正的机会。
- 用多种估值方法交叉验证内在价值。

## 常见陷阱

- 把波动当成风险，或忽视永久性损失的风险。
- 在流动性差的标的上过度集中。
- 为了相对排名而被迫冒险。
