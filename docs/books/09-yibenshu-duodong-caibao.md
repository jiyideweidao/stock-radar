# 《一本书读懂财报》提要

- 分层：基础类
- 作者：肖星（2014 年）
- 主题：财报三表入门
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 资产负债表看家底（时点），利润表看业绩（期间），现金流量表看真假（期间）。
2. 利润不等于现金；盈利的公司也可能因现金流断裂而倒下。
3. 三张表互相关联，同一笔业务会在多张表留下痕迹，可相互印证。
4. 财务分析要回答三件事：赚不赚钱、赚的是不是真钱、有没有风险。

## 可执行方法

- 先看整体结构：资产里有多少货币资金、应收、存货、固定资产。
- 用「净利润 → 经营现金流」的落差判断利润含金量。
- 关注应收账款与存货增速是否快于收入增速。
- 用毛利率、净利率与同业对比找出异常。

## 常见陷阱

- 只看净利润，不看现金流与资产负债结构。
- 被营收增长迷惑：增长可能全部来自赊销与囤货。
- 忽视非经常性损益对利润的贡献。
