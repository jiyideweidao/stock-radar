# 《炒股的智慧》提要

- 分层：基础类
- 作者：陈江挺（1999 年）
- 说明：作者以华尔街实战经验写就，兼具交易心理与操作纪律，被称为华人散户的必读入门书。
- 主题：散户的投机纪律
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 炒股是概率游戏，没人能次次看对；关键是错的时候亏得少、对的时候赚得多。
2. 败而不倒：保住本金，才能留在场内等下一次机会。
3. 华尔街没有新鲜事，人性与情绪在市场中反复重演。
4. 知识不是力量，行动才是：知道规则还要能执行规则。

## 可执行方法

- 只在趋势明确、价量配合时进场，不猜底、不抄底。
- 买入即设止损，止损位随股价上移（移动止损），锁住利润。
- 分批进场降低择时压力，加仓只在盈利之后进行。
- 把交易写成书面计划：进场理由、止损、目标、仓位。

## 常见陷阱

- 摊平亏损（向下加仓）是散户最常见的爆仓方式。
- 满仓单只股票，把小错误变成大错误。
- 频繁交易、听消息、追涨停。
