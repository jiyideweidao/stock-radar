# 《巴菲特致股东的信》提要

- 分层：进阶类
- 作者：沃伦·巴菲特 (Warren Buffett)（1977 年）
- 主题：经营视角的投资
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 买股票就是买公司的一部分，关注企业长期经营而非股价短期波动。
2. 护城河与定价权是长期竞争优势的来源。
3. 用「所有者」心态看待持股，用「市场先生」心态看待报价。
4. 诚信与能力并重的管理层，是长期复利的前提。

## 可执行方法

- 用「内在价值 vs 市场价格」的差距决定买卖。
- 只投资能力圈内、未来现金流可预测的生意。
- 集中投资于少数优质公司，长期持有。
- 用留存收益的再投资效率（ROE、ROIC）衡量管理层。

## 常见陷阱

- 频繁交易与过度分散，稀释研究深度。
- 被短期业绩与市场情绪牵着走。
- 在能力圈外下重注。
