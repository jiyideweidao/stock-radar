# 《文明、现代化、价值投资与中国》提要

- 分层：高阶类
- 作者：李录（2020 年）
- 主题：价值投资与中国市场
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 价值投资是普适的方法论，核心是「内在价值」与「安全边际」。
2. 现代化与文明的演进，决定了长期投资的环境与机会。
3. 中国市场的长期机会来自经济增长与企业价值创造。
4. 理性、耐心与独立思考，是长期投资的关键。

## 可执行方法

- 用价值投资的框架寻找中国的优质企业。
- 关注企业的长期竞争力与现金流，而非短期波动。
- 保持理性与独立思考，不被市场情绪左右。
- 长期持有，做时间的朋友。

## 常见陷阱

- 用短期视角看待长期机会。
- 盲目跟风，缺乏独立判断。
- 忽视估值与安全边际。
