# 《投资最重要的事》提要

- 分层：高阶类
- 作者：霍华德·马克斯 (Howard Marks)（2011 年）
- 主题：风险与周期
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资的核心是「控制风险」，而不是追求最高收益。
2. 市场具有周期性，钟摆总在乐观与悲观之间摆动。
3. 第二层思维：比市场想得更深，才能获得超额收益。
4. 在价格低于价值时买入，留足安全边际。

## 可执行方法

- 用「第二层思维」质疑共识：别人怎么看，我的不同在哪里？
- 逆向投资：极度悲观时买入，极度乐观时谨慎。
- 关注风险调整后收益，而非绝对收益。
- 用周期位置判断风险偏好：高位防守，低位进攻。

## 常见陷阱

- 只追求高收益而忽略风险。
- 在周期顶部过度乐观、加杠杆。
- 用「这次不一样」为泡沫辩护。
