# 《战胜华尔街》提要

- 分层：进阶类
- 作者：彼得·林奇 (Peter Lynch)（1993 年）
- 主题：组合管理与个股研究
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 业余投资者可以战胜华尔街，关键是用功研究与耐心。
2. 分散化要适度：过度分散等于没有观点。
3. 卖出要有理由：基本面变坏才卖，而不是因为股价波动。
4. 从生活中发现机会，再回到基本面验证。

## 可执行方法

- 用「两分钟独白」检验买入理由是否成立。
- 用 PEG 等指标辅助判断成长股估值是否合理。
- 定期检查持仓的「故事」是否变坏，剔除基本面恶化的标的。
- 在市场恐慌、优质公司被错杀时逆向买入。

## 常见陷阱

- 「拔掉鲜花，浇灌杂草」：卖掉赚钱的，留下亏钱的。
- 追热门股、追涨杀跌。
- 因为宏观预测而放弃个股研究。
