# 《价值投资实战手册》提要

- 分层：进阶类
- 作者：唐朝（2020 年）
- 主题：估值与价值投资实操
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资只需解决三个问题：买什么、多少钱买、什么时候卖。
2. 估值是模糊的正确，追求区间而非精确点位。
3. 不预测市场，只利用市场报价。
4. 价值投资的本质是「用五毛买一块」。

## 可执行方法

- 用「三年后合理估值的五折」作为买点，在合理估值的1.5倍以上考虑卖出。
- 用现金流折现与净利润增速估算合理估值区间。
- 建立能力圈内的股票池，长期跟踪。
- 把交易写下来：买点、卖点、逻辑，减少情绪干扰。

## 常见陷阱

- 追求精确估值，陷入「精确的错误」。
- 在合理估值之上买入，牺牲安全边际。
- 因为短期波动推翻长期逻辑。
