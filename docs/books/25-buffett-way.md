# 《巴菲特之道》提要

- 分层：高阶类
- 作者：罗伯特·哈格斯特朗 (Robert Hagstrom)（1994 年）
- 主题：巴菲特投资方法系统化
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 巴菲特的方法可归纳为：企业视角、安全边际、市场先生、能力圈。
2. 四条准则十二项：企业准则、管理准则、财务准则、市场准则。
3. 用「内在价值」而非「股价」衡量投资。
4. 长期持有优质企业，让复利发挥威力。

## 可执行方法

- 用十二项准则系统筛选：业务是否简单易懂、是否有护城河、管理层是否理性诚信、盈利能力是否稳健、是否值得长期持有。
- 计算内在价值并与市价比较，留足安全边际。
- 集中投资，长期持有。
- 把市场波动视为机会，而非风险。

## 常见陷阱

- 把巴菲特的方法简化为「长期持有」，忽略估值与质量。
- 在能力圈外盲目模仿。
- 在高估时买入优质公司，牺牲安全边际。
