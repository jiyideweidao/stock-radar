# 《竞争战略》提要

- 分层：拓展阅读（非交易规则）
- 作者：迈克尔·波特 (Michael Porter)（1980 年）
- 说明：属战略管理经典，此处提炼用于判断企业护城河与行业格局，是选股的上游分析工具。
- 主题：行业结构与竞争优势
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 行业结构决定长期盈利水平，五种力量决定竞争强度。
2. 企业需要建立可持续的竞争优势：成本领先、差异化、聚焦。
3. 竞争战略的核心是「选择不做什么」。
4. 价值链分析帮助识别真正的竞争优势来源。

## 可执行方法

- 用五力模型分析行业：供应商、买方、替代品、新进入者、同业竞争。
- 用三大通用战略定位企业：成本领先、差异化、聚焦。
- 用价值链拆解成本与差异化的来源。
- 分析竞争对手的反应与行业演变趋势。

## 常见陷阱

- 卡在中间：既没有成本优势也没有差异化。
- 忽视行业结构，只看公司自身。
- 把短期战术当成长期战略。
