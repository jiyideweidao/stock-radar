# 《股剩是怎么炼成的》类散户生存读物提要

- 说明：中文市场存在多个同名或近名的散户生存类读物，作者与版本较多，此处为方法论归纳，非原文摘录。
- 主题：散户的生存法则、反人性操作、仓位与周期的关系。

## 核心观点

1. 「剩」者为王：活下来比赚快钱重要。熊市空仓也是一种操作，不参与不需要理由。
2. 散户的优势是灵活、无排名考核压力；劣势是信息、资金与专业工具。
3. 情绪是散户最大的对手盘：贪婪让人买在顶部，恐惧让人卖在底部。
4. 周期比选股重要：在错误的周期里，好公司也会下跌。

## 可执行方法

- **仓位跟随确定性**：确定性高时重仓，确定性低时轻仓或空仓，而不是长期满仓。
- **设定年度最大回撤线**：触及后强制降低仓位并复盘，而不是加大仓位挽回。
- **拒绝处置效应**：不因为「回本了」就卖，也不因为「亏太多」就扛。
- **用规则替代盘感**：把买卖条件写成可检验的条目，减少临时决策。

## 常见陷阱

- 把偶然的盈利当成能力，进而放大仓位。
- 在下跌中不断补仓，用加仓来证明自己最初的判断没错。
- 空仓焦虑：因为「怕错过」而在没有信号时买入。
