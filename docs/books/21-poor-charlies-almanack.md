# 《穷查理宝典》提要

- 分层：进阶类
- 作者：查理·芒格 (Charlie Munger)（2005 年）
- 主题：多元思维模型与理性
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 用「多元思维模型」理解世界：把心理学、数学、经济学等学科的模型组合起来。
2. 反过来想：先想「怎么会失败」，从而避免错误。
3. 理性、诚实、终身学习，是长期复利的基石。
4. 用检查清单防止愚蠢，而不是追求聪明。

## 可执行方法

- 建立并维护自己的思维模型清单，多模型交叉验证。
- 逆向思考找风险：如果要毁掉这笔投资，会怎么做？
- 用「能力圈 + 安全边际」做决策，只在有把握时下重注。
- 持续阅读，扩展认知边界。

## 常见陷阱

- 单一模型看世界（拿锤子的人看什么都像钉子）。
- 被激励结构误导，忽视利益关系对判断的影响。
- 情绪化决策与过度自信。
