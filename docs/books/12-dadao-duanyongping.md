# 《大道：段永平投资问答录》提要

- 分层：基础类
- 作者：段永平（2020 年）
- 主题：本分、常识与长期主义
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 买股票就是买公司，买公司就是买其未来现金流的折现。
2. 本分：做对的事情，把事情做对；不赚不该赚的钱。
3. 「不为清单」比「作为清单」更重要：知道不做什么，比知道做什么更关键。
4. 能力圈之外的机会不是机会，是风险。

## 可执行方法

- 只投自己能看懂、且相信十年后依然好的生意。
- 用「生意模式 + 企业文化 + 合理价格」三要素筛选。
- 逆向：别人恐惧时敢买，但前提是价值判断成立。
- 长期持有优质公司，减少交易，把精力放在理解生意上。

## 常见陷阱

- 用短期股价衡量决策对错；股价下跌不等于判断错误。
- 加杠杆、做空、投机博弈，超出能力圈下重注。
- 频繁换股，把投资做成交易。
