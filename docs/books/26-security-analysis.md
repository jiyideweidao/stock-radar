# 《证券分析（第6版）》提要

- 分层：高阶类
- 作者：本杰明·格雷厄姆 / 戴维·多德（1934 年）
- 主题：证券分析体系
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资的核心是「安全边际」与「本金安全」。
2. 分析要基于事实与数据，而非预测与情绪。
3. 区分投资与投机，区分内在价值与市场价格。
4. 稳健的分析应能抵御不确定性与错误。

## 可执行方法

- 用财务数据评估内在价值：资产、盈利、股息、稳定性。
- 用「净流动资产价值」（净净值）等定量标准寻找低估标的。
- 用固定收益与优先股的分析框架评估债券安全性。
- 分散化配置，降低单一标的的风险。

## 常见陷阱

- 用预测代替分析，把希望当依据。
- 忽视安全边际，在估值过高时买入。
- 把投机性的操作当成投资。
