# 《股票大作手回忆录》提要

- 作者：埃德温·勒菲弗（Edwin Lefevre），1923 年首次出版；主人公原型为杰西·利弗莫尔。该书在美国已进入公有领域，可自由整理与引用。
- 主题：趋势投机、市场情绪、投机者的自我管理。

## 核心观点

1. 市场永远是对的。错的只能是判断；亏损必须在第一时间承认，而不是与行情争辩。
2. 价格沿「最小阻力线」运动。先判断大方向，再等待关键点位给出确认，而不是预测拐点。
3. 赚大钱靠的是「持有」，不是频繁交易。看对方向只是第一步，坐得住才是收益来源。
4. 内幕消息、喊单、股评是散户最大的成本来源。任何不是自己研究得出的结论都不足以支撑仓位。
5. 市场只有三种状态：上升、下降、震荡。震荡期最消耗本金与耐心。

## 可执行方法

- **关键点买入**：在放量突破整理平台或前期高点时进场，而不是在平台内部提前埋伏。
- **试仓—确认—加码**：先用小仓位验证方向，方向正确再加码；方向错误立即离场。
- **顺势加仓、逆势减仓**：仓位方向永远与趋势一致，不做一次性满仓押注。
- **不摊平亏损**：亏损加仓是把错误放大，而不是把成本降低。

## 常见陷阱

- 亏损后加倍下注摊平成本——作者本人承认的最大败因。
- 把「看对行情」等同于「赚到钱」，忽略仓位管理与进场时机。
- 在震荡市中反复交易，被手续费与滑点持续消耗。
