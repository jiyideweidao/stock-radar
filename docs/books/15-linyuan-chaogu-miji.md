# 《林园炒股秘籍（精装增补版）》提要

- 分层：基础类
- 作者：王洪（2007 年）
- 说明：记录林园的投资理念与选股方法，属实战经验整理，非学术著作。
- 主题：中国式价值投资与选股
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 只投「赚钱机器」：毛利率高、现金流好、能持续赚钱的垄断型公司。
2. 选行业比选公司更重要，偏好与「嘴巴」相关的确定性行业（消费、医药）。
3. 长期持有，做时间的朋友；好公司不怕贵，怕买错。
4. 不懂不做，看不懂的行业坚决不碰。

## 可执行方法

- 用「三好」标准筛选：好行业、好公司、好价格。
- 关注护城河：品牌、垄断、定价权。
- 集中持有少数几只看得懂的好公司，长期不动。
- 在行业或个股被错杀、估值合理时买入。

## 常见陷阱

- 追热点、追概念，买入看不懂的公司。
- 因为短期波动频繁卖出好公司。
- 忽视估值，在极度高估时买入。
