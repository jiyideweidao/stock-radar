# 《价值：我对投资的思考》提要

- 分层：高阶类
- 作者：张磊（2020 年）
- 主题：长期主义与价值创造
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 长期主义：把时间和精力投入到长期有价值的事情上。
2. 投资的本质是「发现价值、创造价值」。
3. 守正用奇：在坚守原则的基础上灵活创新。
4. 重仓中国、重仓未来，相信长期增长。

## 可执行方法

- 用「长期主义」的视角选择行业与公司。
- 关注企业的护城河与长期竞争力。
- 深度研究，做时间的朋友。
- 「弱水三千，只取一瓢」：做深度而非广度。

## 常见陷阱

- 追逐短期热点，忽视长期价值。
- 缺乏独立判断，盲目跟风。
- 在估值过高时买入，牺牲安全边际。
