# 《漫步华尔街（第13版）》提要

- 分层：基础类
- 作者：伯顿·马尔基尔 (Burton Malkiel)（1973 年）
- 主题：有效市场与指数化投资
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 股价已反映已知信息，绝大多数主动管理者长期跑不赢指数（扣除费用后）。
2. 「随机漫步」：短期价格变动近似随机，不可预测。
3. 长期看股票回报优于债券与现金，但波动巨大。
4. 资产配置与成本，是决定长期结果的关键变量。

## 可执行方法

- 定期定额买入低费率宽基指数基金，长期持有。
- 按年龄与风险承受力做股债配置，并定期再平衡。
- 用生命周期思路：年轻时多权益，临近用钱转债券。
- 控制成本：费率、税、换手都是复利的天敌。

## 常见陷阱

- 相信自己或「专家」能持续择时与选股。
- 追逐热门基金与近期业绩冠军。
- 高换手、高费率，长期被成本侵蚀。
