# 《投资中不简单的事》提要

- 分层：高阶类
- 作者：邱国鹭 等（2017 年）
- 说明：为高毅资产投研团队的文章合集，是多位基金经理的实战观点汇编。
- 主题：中国价值投资实践
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资中「简单」的是原则，「不简单」的是执行与坚持。
2. 便宜买好货，是穿越牛熊的核心逻辑。
3. 用产业的视角看公司，用长期的视角看波动。
4. 逆向与耐心，是超额收益的来源。

## 可执行方法

- 用「行业格局—公司竞争力—估值」三层框架选股。
- 逆向布局被错杀的优质公司。
- 控制回撤，重视仓位管理。
- 持续学习，扩展能力圈。

## 常见陷阱

- 被短期业绩与市场情绪影响。
- 在热门赛道拥挤时买入。
- 忽视估值与风险。
