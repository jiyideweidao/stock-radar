# 《投资中最简单的事》提要

- 分层：进阶类
- 作者：邱国鹭（2014 年）
- 主题：中国市场的价值投资实践
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资的本质是「便宜买好货」：好行业、好公司、好价格。
2. 便宜是硬道理，估值是投资的锚。
3. 人多的地方不去，逆向思维是超额收益的来源之一。
4. 「胜而后求战」：先选确定性高的赛道，再选公司。

## 可执行方法

- 三问：行业格局、公司竞争力、估值水平。
- 「数月亮，不数星星」：选行业龙头，集中且确定。
- 关注估值分位与行业景气，避免在泡沫中追高。
- 用「便宜、质优、有催化」三重过滤选股。

## 常见陷阱

- 为「故事」和高成长付过高价格。
- 在热门赛道拥挤时买入。
- 忽视估值，把「好公司」等同于「好股票」。
