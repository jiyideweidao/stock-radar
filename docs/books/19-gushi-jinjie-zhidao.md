# 《股市进阶之道：一个散户的自我修养》提要

- 分层：进阶类
- 作者：李杰（水晶苍蝇拍）（2014 年）
- 主题：从散户到体系化投资
- 性质：方法论学习提要，非原文摘录，未下载或分发原书 PDF。

## 核心观点

1. 投资要先建立体系：认知、方法、纪律三件事缺一不可。
2. 复利的核心是「不亏大钱」，控制回撤比追求高收益更重要。
3. 理解市场先生的情绪，但用企业价值做锚。
4. 学习是投资者的核心竞争力，认知边界决定收益边界。

## 可执行方法

- 建立自己的投资体系：选股标准、买入条件、卖出条件、仓位规则。
- 用绝对估值（DCF）与相对估值交叉验证内在价值。
- 逆向布局：在行业低迷、估值低位时买入优质公司。
- 记录并复盘，形成可迭代的决策流程。

## 常见陷阱

- 没有体系，靠感觉与消息做决策。
- 在情绪高点重仓，回撤时被迫离场。
- 只看收益、不看风险，忽略仓位管理。
